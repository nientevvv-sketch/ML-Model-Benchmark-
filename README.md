# ML Model Benchmark

A machine learning project that compares four classification algorithms on the Breast Cancer Wisconsin dataset from scikit-learn.

The project demonstrates a supervised machine learning workflow, including data preparation, hyperparameter tuning, cross-validation, model evaluation, and visualisation.

**Disclaimer:** This project is for educational and portfolio purposes only. It is not intended for clinical diagnosis or real-world medical decision-making.

## Project Goal

The goal is to compare four classification algorithms and evaluate how effectively they identify malignant cases.

The models are:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Dataset

The project uses the Breast Cancer Wisconsin (Diagnostic) dataset provided by scikit-learn.

- Samples: 569
- Features: 30 numerical features
- Classes: malignant and benign
- Training samples: 455
- Test samples: 114

The dataset is split into training and test sets using an 80/20 split, with `random_state=42` and stratification.

## Methodology

The project follows these steps:

1. Load the dataset.
2. Split the data into training and test sets.
3. Define baseline classification models.
4. Tune hyperparameters using `GridSearchCV`.
5. Use stratified 5-fold cross-validation during hyperparameter tuning.
6. Select parameters by the F1-score for the malignant class.
7. Evaluate the tuned models on the held-out test set.
8. Save metrics, selected parameters, classification reports, and visualisations.

The test set is kept separate from hyperparameter selection and is used for final evaluation.

## Evaluation Metrics

- **Accuracy:** the proportion of all predictions that are correct.
- **Precision (malignant):** the proportion of predicted malignant cases that are actually malignant.
- **Recall (malignant):** the proportion of actual malignant cases correctly identified.
- **F1-score (malignant):** the harmonic mean of malignant-class precision and recall.
- **ROC-AUC (malignant):** measures how well the model ranks malignant cases above benign cases across classification thresholds.
- **Training time:** the time required to fit a model on the training set.
