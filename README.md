# ML Model Benchmark

A machine learning project that compares four classification algorithms on the Breast Cancer Wisconsin dataset from scikit-learn.

The project demonstrates a supervised machine learning workflow, including data preparation, hyperparameter tuning, cross-validation, model evaluation, and visualisation.

**Disclaimer:** This project is for educational and portfolio purposes only. It is not intended for clinical diagnosis or real-world medical decision-making.

## Project Goal

The goal is to compare four classification algorithms and evaluate how effectively they identify malignant cases.

The models are:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Dataset

The project uses the Breast Cancer Wisconsin (Diagnostic) dataset provided by scikit-learn.

- Samples: 569
- Features: 30 numerical features
- Classes: malignant and benign
- Training samples: 455
- Test samples: 114

The dataset is split into training and test sets using an 80/20 split, with `random_state=42` and stratification.

## Methodology

The project follows these steps:

1. Load the dataset.
2. Split the data into training and test sets.
3. Define baseline classification models.
4. Tune hyperparameters using `GridSearchCV`.
5. Use stratified 5-fold cross-validation during hyperparameter tuning.
6. Select parameters by the F1-score for the malignant class.
7. Evaluate the tuned models on the held-out test set.
8. Save metrics, selected parameters, classification reports, and visualisations.

The test set is kept separate from hyperparameter selection and is used for final evaluation.

## Evaluation Metrics

- **Accuracy:** the proportion of all predictions that are correct.
- **Precision (malignant):** the proportion of predicted malignant cases that are actually malignant.
- **Recall (malignant):** the proportion of actual malignant cases correctly identified.
- **F1-score (malignant):** the harmonic mean of malignant-class precision and recall.
- **ROC-AUC (malignant):** measures how well the model ranks malignant cases above benign cases across classification thresholds.
- **Training time:** the time required to fit a model on the training set.

## Results

Results are generated by running `main.py`. The final metrics are saved to `results/final_report.csv`, and the selected hyperparameters are saved to `results/best_hyperparameters.csv`.

## Model Comparison

All models were evaluated on the same held-out test set of 114 samples.
Hyperparameter selection and nested cross-validation were performed using
the training set only.

| Model | Nested CV F1 (mean ± std) | Best CV F1 | Test Accuracy | Test Precision (malignant) | Test Recall (malignant) | Test F1 (malignant) | Test ROC-AUC | Training Time (s) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.9595 ± 0.0098 | 0.9760 | 0.9737 | 0.9756 | 0.9524 | **0.9639** | 0.9957 | 0.0242 |
| Gradient Boosting | 0.9554 ± 0.0250 | 0.9557 | 0.9474 | 0.9500 | 0.9048 | 0.9268 | 0.9914 | 0.9055 |
| Random Forest | 0.9467 ± 0.0223 | 0.9533 | 0.9474 | 0.9286 | 0.9286 | 0.9286 | 0.9937 | 0.9063 |
| Decision Tree | 0.8952 ± 0.0348 | 0.9183 | 0.9123 | 0.8636 | 0.9048 | 0.8837 | 0.9375 | 0.0111 |

### Key Findings

- **Best overall model:** Logistic Regression achieved the highest test F1-score for the malignant class (0.9639) and the highest test accuracy (97.37%).
- **Best cross-validation performance:** Logistic Regression achieved a nested CV F1-score of 0.9595 ± 0.0098, showing consistent performance across folds.
- **Best ROC-AUC:** Logistic Regression achieved 0.9957, indicating excellent discrimination between malignant and benign cases on this test set.
- **Fastest model:** Logistic Regression had a measured training time of 0.0242 seconds, excluding hyperparameter search and other pipeline overhead.
- **Weakest model:** Decision Tree had the lowest test F1-score (0.8837) and test accuracy (91.23%).

### Conclusion

Logistic Regression was the strongest model in this experiment, balancing
high predictive performance, cross-validation stability, and low training
cost. Random Forest and Gradient Boosting also achieved strong results,
while the single Decision Tree performed less effectively.

These results are based on a small benchmark dataset and do not establish
clinical suitability. The models are intended for educational and research
purposes, not medical diagnosis.

##  Installation

**Requirements:** Python 3.10 or newer.

### 1. Clone the repository

```bash
git clone https://github.com/nientevvv-sketch/ML-Model-Benchmark-.git
cd ML-Model-Benchmark-
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it using the command appropriate for your operating system.

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### Computer Vision Benchmark: CIFAR-10

The computer vision benchmark compares a custom Convolutional Neural Network (CNN) with ResNet18 on a subset of the CIFAR-10 dataset.

**Experimental setup**
- Dataset: CIFAR-10 (10 classes)
- Training subset: 4,500 images
- Validation subset: 500 images
- Test subset: 1,000 images
- Epochs per model: 2
- Hardware: CPU-only

**Results**

| Model | Test Accuracy | Macro F1 | Training Time |
|---|---:|---:|---:|
| CNN | 41.20% | 35.81% | 9.02 s |
| ResNet18 | 37.50% | 33.25% | 326.63 s |

**Conclusion & Limitations**

Under the current experimental settings the custom CNN outperformed ResNet18 on this benchmark: it achieved higher test accuracy and higher macro F1 while requiring substantially less training time.

However, these findings are preliminary and should be interpreted with caution. The experiment used a small subset of CIFAR-10 and only two training epochs, so the comparison is not comprehensive.
